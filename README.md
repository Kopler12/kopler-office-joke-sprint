Entry for the make.fun competition [One-Line Office Joke: 24-Hour Sprint](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162). `main.py` writes a single line — a joke about the daily standup that long ago stopped being quick — to `/output/entry.txt`.

> Our daily standup runs 45 minutes now — we only stand because sitting down would mean admitting it's a meeting.

The joke lands on a detail every office worker recognises: the "quick" standup that quietly became a full meeting, with everyone still on their feet pretending otherwise. One line, 111 characters.

Run it with `python3 main.py`; it needs no network and writes only `/output/entry.txt`.
